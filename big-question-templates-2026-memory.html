一页总公式

论述题万能公式

  1. 开头定性：这是落实立德树人根本任务的重要内容。
  2. 理论依据：立德树人、三全育人、以学生为中心、价值引领。
  3. 主体四点：提高站位、融入日常、创新载体、完善机制。
  4. 结尾升华：培养德智体美劳全面发展的社会主义建设者和接班人。
我认为，这项工作本质上是新时代高校落实立德树人根本任务的具体体现，必须坚持价值引领、问题导向和机制保障相统一，推动相关要求落到实处、取得实效。

案例题万能公式

  1. 先表态：高度重视，坚持以学生为中心。
  2. 再定性：既是管理问题，也是育人问题。
  3. 先处置：第一时间了解情况、稳定情绪。
  4. 再解决：核实原因、分类施策、协同联动。
  5. 再教育：谈心谈话、规则教育、心理疏导。
  6. 再巩固：建立台账、跟踪回访、完善机制。
我会坚持“先共情、后核实、再解决、再教育、再巩固”的思路，既解决学生现实困难，又做好思想引导和规则教育。

发言稿万能公式

  1. 称呼问候。
  2. 开头点题：身份 + 场合 + 感谢 + 主题。
  3. 形势意义：为什么重要。
  4. 主体四点：强化引领、搭建平台、优化服务、精准帮扶。
  5. 结尾：下一步打算 + 祝愿感谢。
尊敬的各位领导、老师，亲爱的同学们，大家好。很荣幸参加本次活动名称，下面我围绕主题谈几点认识和体会。

案例题速背卡

重点背标题

宿舍问题

  1. 第一时间回应诉求，安抚情绪。
  2. 深入宿舍核实情况，摸清噪音和设施问题。
  3. 联合后勤、宿管分类解决。
  4. 合理调宿按制度办理。
  5. 组织沟通，制定宿舍公约。
  6. 加强新生适应教育和宿舍文化建设。
这是新生适应教育、学生事务管理和宿舍育人问题。我会坚持以学生为中心，先安抚、再核实、再协调、再教育、再巩固。

爱国主义教育

  1. 强化理论武装，讲好四史。
  2. 融入主题班会、党团活动和日常教育。
  3. 用好红色基地、社会实践和志愿服务。
  4. 善用新媒体讲好中国故事。
  5. 结合艺术实践、红色音乐和美育活动。
要把爱国主义教育融入日常、抓在经常，引导学生把爱国之情转化为报国之志和强国之行。

心理危机

  1. 生命至上，安全第一。
  2. 第一时间陪伴学生，稳定情绪。
  3. 及时报告学院、心理中心、相关部门。
  4. 必要时联系家长和医疗资源。
  5. 后续做好回访和支持。

学风诚信

  1. 定性为学风建设和诚信教育问题。
  2. 教育在先，程序规范，处理公正。
  3. 加强考风考纪和学术规范教育。
  4. 分类帮扶，营造勤学诚信氛围。

网络舆情突发

  1. 第一时间核实真伪并上报。
  2. 及时回应关切，稳定情绪。
  3. 统一口径，协同处置。
  4. 事后复盘，完善预案。

就业帮扶

  1. 树立正确就业观。
  2. 建立一人一档、一人一策。
  3. 强化简历、面试、岗位推荐服务。
  4. 鼓励基层就业、多元就业和创新创业。

  1. 先写一个总判断句。
  2. 马上列 4 个分点标题。
  3. 每点写 2 到 3 句动作。
  4. 结尾再写一句目标升华。
