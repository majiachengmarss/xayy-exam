## 🚀 快速开始

### 本地查看
```bash
# 克隆仓库
git clone https://github.com/majiachengmarss/xayy-exam.git

# 进入目录
cd xayy-exam

# 用浏览器打开 index.html
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### 启用GitHub Pages
1. 进入仓库的 Settings 页面
2. 找到 "Pages" 选项
3. 在 "Source" 下选择 "main" 分支
4. 点击 "Save"
5. 等待几分钟后即可通过 `https://majiachengmarss.github.io/xayy-exam/` 访问
